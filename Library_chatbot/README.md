# Library Bookmate

A standalone, searchable book discovery website for engineering students and general readers.

## Run it

1. Open this folder in Visual Studio Code.
2. Open `index.html` in a browser, or use VS Code Live Server and choose **Open with Live Server**.

No install or build step is required. The catalogue contains curated recommendations, not live holdings from any one library. Confirm local availability and editions with your library.
